# Syberia DataMine
A crappy project to view and extract files from the games Syberia and Syberia II

# Current status
- Supports rendering and export of videos, audios, meshes, textures, 3d objects, behaviors and more
- Has small issue where not all 3d object would render correctly
- Models are generally missing textures in preview. TODO: resolve and render them as well

# Requirements
- Visual Studio 2026
- .NET SDK 10.0 & .NET 10.0 Build TOols
- At least 1 brain cell
